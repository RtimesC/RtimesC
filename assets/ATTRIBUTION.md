# Visual attribution

## Hero lettering

The monoline lettering, pen paths, animation timing, and color system were
created specifically for this profile. The SVG contains no external font,
script, or runtime dependency.

## Human–robot animation

“Man and robot with computers sitting together in workplace” is by
[Abdul Latif](https://lottiefiles.com/animoox) and was downloaded from its
[LottieFiles community page](https://lottiefiles.com/free-animation/man-and-robot-with-computers-sitting-together-in-workplace-QnbODCGAFt).
The page identifies it as free to use under the
[Lottie Simple License](https://lottiefiles.com/page/license).

The repository GIF is a locally rendered and optimized derivative of the
original vector animation. It is not offered as a standalone asset.
